# 홍예 — 도깨비 다리

프롤로그·1장용 자체 제작 게임 그림. 2026-10-16 OpenAI 내장 image_gen으로 생성한 픽셀 화풍 배경과 인물이다. 외부 게임의 스프라이트·그림을 전재하지 않았다.

- `v0.2.0/`: 박물관·마당·밤 들판, 장소 아틀라스 두 장(저자/성벽/절/갱/귀족 집/남천/대릉/왕궁), 기본 인물·추가 인물, 이수 걷기·전투 자세. 모두 원본 PNG 크기를 유지한 WebP 인코딩이다.
- 투명 인물 시트는 실제 알파를 포함한다. 런타임에서 셀별 경계를 읽어 그린다.
- 실제 프롬프트·참조 관계는 GDI-Apps `game/hongye/doc/art-prompts.json`, 파일 해시와 셀 배치는 `v0.2.0/manifest.json`에 기록했다.
- 복식·건축의 역사적 정확성을 검증한 자료는 아니다. 역사 고증 감수는 후속 제작 항목이다.

# Studio DK 로고

| 파일 | 쓰임 |
|---|---|
| `studiodk-logo-main.*` | 메인 로고(펼친 책이 D, 불꽃이 K) — 메인 랜딩 |
| `studiodk-logo-main-dark.*` | 메인 로고, 어두운 바탕용 |
| `studiodk-logo-sub.*` | 서브 로고(DK 기호 + Studio DK 가로형) — 꼬리말·다른 사이트 머리 |
| `studiodk-logo-sub-dark.*` | 서브 로고, 어두운 바탕용 |
| `studiodk-mark.png`, `-32`, `-180`, `-192` | DK 기호만 — 탭 아이콘·앱 아이콘 |
| `원본-메인.png`, `원본-서브.png` | 다듬기 전 원본(흰 바탕, 1024px) |

투명 배경으로 다듬은 판이다. 로고는 Studio DK(딸깍창작실)의 표지이므로 다른 곳에서 쓰거나 고치지 않는다. 그 밖의 Studio DK 창작물은 CC BY-NC-ND 4.0 이다.

# 게임 배경음

Studio DK 게임 여섯(The Tower·과제 지옥·딸깍그랑프리·새벽바라기·귀농일기·해동삼국지)의 배경음 64곡.

- 만든 방법: 음악 생성 모델 ACE-Step 1.5(MIT 사용권)를 개인 PC 에서 돌려 만든 연주곡(2026-10-15). 가사 없음
- 손질: 음량을 -19 LUFS(참 꼭대기 -1.5dB)로 맞추고 44.1kHz 스테레오 128kbps mp3 로 다시 저장
- 곡마다 설명·빠르기·길이는 각 게임 코드의 곡 목록에 있다

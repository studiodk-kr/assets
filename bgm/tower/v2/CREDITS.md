# tower BGM v2 — 2026-11-08

새로 제작한 장면별 기악 배경음악 1곡이다. 기존 음악은 원래 경로에 보존한다.

연결된 YuE2 생성 서비스로 직접 작성한 독자 ABC 악보와 게임·장면별 악기 지시문을 렌더했다. 이전 기악곡의 생성 문맥을 이용하되 모든 선율·화성 악보를 새로 작성했으며 기존 게임 곡의 선율을 재사용하거나 특정 곡·가수의 모사를 요청하지 않았다. 입력 악보와 서비스의 반환 악보가 일치한다. 타이틀에는 짧은 도입, 대비되는 중간 선율, 후반 변주를 넣었다. 악보 수준에서 동일한4마디 구절의 완전 반복 X. 모델 연주에서의 반복감·음악성은 별도의 청음 대상이다. 실제 연주 녹음·사람의 전곡 청음 완료·고대음악의 복원 주장 X.

무손실 원본을 두 차례 loudnorm으로 측정·조정해48kHz/스테레오/160kbps MP3로 만들었다. 목표-20LUFS/true peak-2dBFS, 앞0.45초·뒤0.7초 페이드. 기존 게임의 곡 전환·반복 재생 정책을 유지하며 완전한 무공백 음악 루프를 보장하지 않는다. 실제 길이·음량·피크·원본/배포본SHA·악보·지시문은 production.json과 각ABC파일에 있다. 원본FLAC·일회성 받기 주소·서비스 키는 공개하지 않는다.

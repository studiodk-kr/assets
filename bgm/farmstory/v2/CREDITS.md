# 경북귀농일기 BGM v2 — 2026-11-08

현재 귀농일기 v2 전용 신규 기악 배경음악 6곡이다. 다른 게임이나 기존 bgm/farmstory 파일은 바꾸지 않는다.

- 타이틀: 다시 여는 마을 — 전개 보강판
- 봄: 봄볕 아래 첫 이랑
- 여름: 여름 밭의 바람

- 겨울: 눈 내린 마당
- 축제: 함께 차리는 잔칫상

연결된 YuE2 생성 서비스로 독자 지시문과 구간 태그를 사용해 제작했다. 기존 곡·가수의 모사를 요청하지 않았다. 타이틀은 초기 시청 피드백에 따라 직접 작성한 ABC 악보로 다시 렌더했다. 도입4마디, 대비 선율·간주·변주·브리지·짧은 마무리의88마디/22개 고유4마디 구절이며, 입력 악보와 서비스가 반환한 악보가 일치한다. 실제 연주 녹음이나 사람의 전곡 청음 완료를 주장하지 않는다.

무손실 원본으로 두 차례 loudnorm 측정·조정 후48kHz/스테레오/160kbps MP3로 만들었다. 목표-20LUFS/true peak-2dBFS, 앞0.45초·뒤0.7초 페이드. 기존 공용 플레이어의 곡 전환·끝4초 교차 재생을 사용한다. 기술 측정과 청감상 완전한 이음매 보장은 구분한다. 각 실제 길이·측정·소스/배포본 SHA와 지시문은 production.json에 있다. 원본 FLAC·일회성 받기 주소·MCP 키는 공개하지 않는다.

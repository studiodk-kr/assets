# Studio DK assets

Studio DK(딸깍창작실) 게임이 불러 쓰는 공개 자원 — 3D 모델·텍스처·효과음·그림.

- 폴더 = 게임 이름(`tower`·`dawn`·`farmstory`·`gdi`·`grandprix`·`sagukji`), 여러 게임이 같이 쓰는 효과음은 `shared/sfx`
- 외부 자원의 출처·라이선스는 폴더마다 `CREDITS.md`
- 믹사모 원본은 약관상 여기 두지 않는다(게임 서버에서만 내보낸다)
- 자체 제작물(게임 그림 등)은 CC BY-NC-ND 4.0, 외부 자원은 각 `CREDITS.md` 의 라이선스를 따른다
